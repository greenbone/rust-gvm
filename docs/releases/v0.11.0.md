# rust-gvm v0.11.0

rust-gvm v0.11.0 preserves the complete open set of references attached to
result and catalog NVTs, while retaining the existing CVE compatibility view.
It also enables explicit clearing of agent-group membership on compatible gvmd
versions, removes the direct unmaintained `chrono` dependency, and includes a
reviewed SSH security update.

Callers upgrading from v0.10.0 should review the
[v0.11.0 migration guide](https://github.com/greenbone-hive/rust-gvm/blob/v0.11.0/docs/v0.11.0-migration.md).
Existing CVE access and schedule APIs remain available. Consumers of serialized
NVT models should account for the new `refs` collection, and callers using
agent-group membership clearing must deploy a gvmd version containing
greenbone/gvmd#3251.

Highlights:

- public `NvtReferenceEntry` values carrying the XML-decoded `type` and `id`
  attributes of generic NVT references;
- `refs` collections on result `NvtRef` and catalog/detail `Nvt` values,
  preserving CERT-Bund, DFN-CERT, URL, and future reference types;
- unchanged `cves` compatibility projection, including the historical direct
  and lower-case `cve` reference behavior;
- serde defaults that continue to accept older serialized NVT values without a
  `refs` field, while malformed reference entries remain non-fatal;
- explicit `<agents/>` encoding for `CollectionUpdate::Clear` and an empty
  replacement, allowing compatible gvmd versions to clear agent-group members;
- replacement of rust-gvm's direct `chrono` dependency with `jiff` while
  retaining strict RFC 3339 validation, UTC normalization, whole-second
  truncation, leap-second behavior, and compact UTC iCalendar handling;
- `russh` 0.65.1, including fixes for GHSA-736f-c93q-9fwx and
  GHSA-9264-jvgf-6w2f, plus reviewed protocol and parser fixes;
- reviewed `serde_json` and `uuid` dependency refreshes and updated Cargo Vet
  evidence;
- release binaries for five targets, each with a SHA-256 checksum;
- the Linux amd64/arm64 mock-server image at
  `ghcr.io/greenbone-hive/gvm-mock-server:v0.11.0` (no moving `latest` tag);
- CycloneDX JSON and XML SBOMs, an SBOM quality report, checksums, and Sigstore
  provenance for downloadable artifacts and the container image.

The release artifacts are built from the immutable `v0.11.0` tag and verified
against its exact qualified protected-main commit before publication completes.
